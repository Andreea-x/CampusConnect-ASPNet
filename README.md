## Project Description
CampusConnect is an ASP.NET Core web application designed to help students and administrators manage campus activities and communication.

### Features
- User registration and login
- Announcements management
- Event management
- Messaging system
- Administrative controls

### Technologies Used
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- Razor Views

### GitHub Repository
https://github.com/aviviscan326-cloud/CampusConnect-ASPNet

## How to Run

1. Clone the repository
2. Open the solution in JetBrains Rider or Visual Studio
3. Restore NuGet packages
4. Run the application

## Installation

- Install .NET 8 SDK
- Clone the repository
- Open the project in Rider or Visual Studio
- Restore dependencies
- Run the application
